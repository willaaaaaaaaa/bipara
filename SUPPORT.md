# Support

Bipara is an experimental source preview for Apple Silicon Macs. For build requirements and current limitations, start with the [README](README.md), [test instructions](Tests/README.md) and [validation status](docs/validation.md).

Use this repository's Issues tab for reproducible bugs, feature requests and usage questions. Search existing issues first. For bugs, include the version or commit, macOS version, reproduction steps and expected/actual behavior. Use a short synthetic text when reporting translation or correspondence problems; identify the provider and model without sharing account details, API keys or private endpoint URLs. Remove personal paths, document contents and credentials from any diagnostic excerpt or screenshot. Full logs are usually unnecessary.

For suspected vulnerabilities, follow [Security reporting](SECURITY.md) and keep details out of public issues. For code or documentation changes, follow [Contributing](CONTRIBUTING.md).

Support is best effort, with no guaranteed response time or provider-account support. Only the latest published release is a maintenance target; source-preview builds have the limitations recorded in validation status.
