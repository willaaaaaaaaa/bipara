# Support

Search existing issues for usage questions, bugs, and feature requests. Include the Bipara version or source commit, macOS version, and Mac chip when reporting a problem. [Bipara Issues](https://github.com/willaaaaaaaaa/bipara/issues)

For a translation problem, include the provider and model, expected and actual behavior, and a short synthetic example. Remove API keys, private endpoints, personal paths, and document contents from screenshots or log excerpts. [Report a bug](https://github.com/willaaaaaaaaa/bipara/issues/new?template=bug_report.md)

Report suspected vulnerabilities privately. [Security reporting](SECURITY.md)
